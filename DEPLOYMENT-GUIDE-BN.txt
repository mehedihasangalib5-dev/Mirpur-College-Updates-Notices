MCUN — Student Portal & Academic Hub Deployment Guide
=====================================================

Ei ZIP-ti tomar uploaded MCUN project-er upor update kore toiri. Existing public site, admin panel, Firebase Auth ebong existing API files rekhe notun Student Portal, Academic Manager ebong secure quiz API jog kora hoyeche.

1) ZIP extract koro
-------------------
MCUN-full-website.zip extract kore project-er sob file tomar GitHub repository-r root-e upload/replace koro. Original project-er folder structure eki rakhbe; index.html, admin.html, api/, firestore.rules, student.html ebong academic-admin.html root-e thakbe.

2) Firebase Firestore Rules publish koro
----------------------------------------
Firebase Console > Firestore Database > Rules e giye ei project-er updated firestore.rules-er puro content paste kore Publish koro.

Ei step miss korle Board Questions, Quiz, Saved Questions ebong Results-er permission error hote pare.

3) Vercel Environment Variables check koro
-----------------------------------------
Vercel Project > Settings > Environment Variables e FIREBASE_SERVICE_ACCOUNT ache kina check koro. Notun /api/academic endpoint existing Firebase Admin SDK helper use kore, tai server-side service account dorkar. Value JSON ba base64 JSON hote pare, existing project-er setup-er sathe mil rekho.

Never put service-account JSON in frontend files.

4) Deploy koro
--------------
GitHub-e push korar por Vercel deploy complete hote dao. Deploy-er por ei route-gulo check koro:
- /
- /admin
- /student.html
- /academic-admin.html
- /api/academic (POST endpoint; browser-e direct open korle 405 expected)

5) Admin workflow
-----------------
- Existing /admin page-e approved Owner/Admin/Editor account diye sign in koro.
- Header-er Academic Manager link ba /academic-admin.html open koro.
- Board Question Bank > Add New Question theke MCQ/CQ content create koro.
- Status Published korle student side-e show korbe.
- Quiz Management > Create New Quiz theke quiz metadata, time, batch, attempt limit ebong MCQ questions add koro.
- Correct answer quizAnswerKeys collection-e private thake; quizQuestions-e answer key add koro na.

6) Student workflow
-------------------
- Student main public site-e existing login/sign-up flow use korbe.
- Email verify kore profile complete korte hobe.
- Tarpor /student.html open korle Student Portal load hobe.
- Board Questions website-e direct text hisebe show hoy; PDF upload/viewer ei initial implementation-e nei.
- Quiz attempt shuru o result submit /api/academic diye server-side e verify hoy.

7) Firestore collections
------------------------
- boardQuestions: student-facing published board question, MCQ/CQ, explanation/solution
- quizSets: quiz metadata and schedule
- quizQuestions: public question text/options; correct answer ekhane rakhbe na
- quizAnswerKeys: staff-only correct answer and explanation
- quizSessions: server-managed quiz sessions
- quizAttempts: server-written attempts/results; student nijer result dekhe, Admin all results dekhe
- users/{uid}/savedQuestions: private saved question list
- users/{uid}/inbox and notifAll: existing notification data read for Communication page

8) Important scope and limitations
----------------------------------
- Existing Firebase project/config reuse kora hoyeche; cloud data automatically migrate/modify kora hoyni.
- Admin-ke real board question and verified answers add korte hobe. Empty state asha normal.
- Board Question form supports MCQ and CQ. Initial Quiz Builder supports single-correct MCQ only.
- Model Test is handled as a timed Exam Mode quiz; multi-select, true/false and numerical response builder ekhono included noy.
- Student Profile currently existing profile theke data read kore; name edit supports existing users/{uid} schema. Academic details existing main-site profile values thekei ashe.
- Student result and progress are based on recorded quiz attempts; kono fake sample score database-e lekha hoy na.
- Firestore Rules publish ebong Vercel environment setup chara production quiz submission/secured results live hobe na.

9) Basic test status
--------------------
Static HTML parsing, inline JavaScript syntax checks, API JavaScript syntax check ebong package.json JSON validation run kora hoyeche. Live Firebase Authentication, Firestore permission, Vercel deployment ebong actual quiz submission credentials/environment chara production-e verify kora hoyni.
